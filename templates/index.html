Quick start
  1. Add an upstream API (Canvas is pre-seeded).
  2. Define permission rules (method + path pattern).
  3. Create internal clients (OpenClaw, scripts, bots).
  4. Grant each client only the rules it should use.
  5. Call /v1/proxy/{api}/{path} with X-Interposer-Key.
